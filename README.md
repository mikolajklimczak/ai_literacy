# AI Literacy and Critical Thinking – Workshop Suite

A collection of standalone, browser-based interactive tools created for the **AI Literacy and Critical Thinking** academic course. 

## Purpose
These applications support practical, hands-on classroom exercises and self-paced student work. They focus on evaluating AI outputs, verifying factual claims, understanding prompt mechanics, and identifying algorithmic or generative manipulation.

## Technical details
- Built as lightweight, single-file HTML/CSS/JavaScript applications.
- Runs directly in any modern web browser without installation, servers, or external dependencies.
- Hosted via GitHub Pages for instant classroom access.
